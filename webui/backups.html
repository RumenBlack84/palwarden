Backups

World-save archives written by palworld-backup and managed by palworld-backups. Everything on this page runs as a job through the palwarden control plane; nothing is done in the browser.

Archives

Download streams the archive to this browser and changes nothing. Restore stops the server and replaces the live world. Delete is the one action here with no undo, so it asks twice.

Import an archive

Two steps on purpose: the file is first streamed to a staging area, then a separate job promotes it into the backups directory. Only names this project wrote are accepted — palworld-save-<UTC stamp>.tar.gz. Importing does not restore anything; the archive appears below as an ordinary row and Restore is still a separate, confirmed action.

Scheduled backups

Read from the schedule file by palworld-backups --if-due on every tick. Saving rewrites all four values together — a partial save is refused by the worker on purpose, so a field left out cannot silently revert to a default. Changes take effect on the next tick, not immediately: nothing here starts or stops a backup that is already due.
