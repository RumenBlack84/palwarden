How this works
  • Defaults: idle timeout 0 (off), check interval 60 s, knock enabled, cooldown 600 s, no token (open doorbell).
  • First attempt is consumed: the UDP packet that wakes the server is spent on the wake — the player's client must retry after startup (typically under a minute).
  • Open doorbell: with no token, any non-empty UDP packet to the game port wakes the server; the cooldown bounds how often. The game's own server password still gates joining — a wake request is not authentication.
  • Token limits: the token is an exact byte comparison. It is not encryption and not replay protection.
  • Partial save: saving merges only the fields you changed, at the moment the job runs. If someone else saves the same field in between, the last save wins — there is no version check.
  • Immediate effect: edits apply within about a second (the next lease boundary or idle tick), without a restart. They cannot undo a start or stop that has already been issued.
  • Persistence: environment seeds apply only while the config file does not exist. Settings saved here live on the ops volume and survive container recreation; changed Compose seeds never overwrite them.
