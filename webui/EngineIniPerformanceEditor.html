Engine.ini performance

Curated Unreal/Palworld performance levers. Values are edited in the browser and written to /etc/palworld/engine.env by the palwarden control plane; palworld-engine-config is what ever touches Engine.ini.

Presets

Presets only fill values in this browser. Review before saving. Higher tick rates may improve smoothness but can raise CPU and network load.

Current Engine.ini

Managed performance settings

The right-hand checkbox marks a key as managed; only managed rows are sent.

Apply via palwarden

Save writes the managed values into /etc/palworld/engine.env and nothing else — no file under Engine.ini changes and the server is untouched, so it is safe at any time. Save and apply additionally runs palworld-engine-config apply and then gracefully restarts the server, warning players first. Applying without restarting is deliberately not offered: Engine.ini only takes effect on restart, so it would leave the file and the running server disagreeing.

Manual apply (bare metal, or when the control plane is unavailable)

sudo install -m 0644 -o root -g root engine.env /etc/palworld/engine.env
sudo /usr/local/sbin/palworld-engine-config apply --dry-run
sudo /usr/local/sbin/palworld-engine-config apply
sudo /usr/local/sbin/palworld-graceful-restart
